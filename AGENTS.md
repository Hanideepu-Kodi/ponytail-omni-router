# AGENTS.md

## Working agreement

- Whatever action you can do yourself, please do yourself. This includes starting apps and verification.
- Complete relevant implementation, setup, and validation work directly instead of asking the user to perform steps that the agent can perform.
- When the project has runnable checks, run the relevant checks after making changes and report anything that could not be verified.

## UI icons

- Use icons only from the Phosphor Icons library.
- Do not introduce icons from other libraries, custom SVG icon sets, Unicode symbols, or emoji as substitutes for UI icons.

## Project direction

- This repository is for an AI Test Agent desktop application powered by OmniRouter.
- Keep implementation decisions minimal until the application architecture and product requirements are established in the repository.
